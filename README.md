# Industrial Demand Forecasting – ML in Production

## Context
This project simulates an industrial demand forecasting problem, similar to production and capacity planning scenarios.

## Goal
Build a reliable forecasting pipeline that:
- handles real-world data
- trains interpretable ML models
- produces forecasts usable by downstream systems

## Dataset
M5 Forecasting Dataset (Walmart sales)

## Approach
- Data ingestion and cleaning
- Feature engineering
- Baseline and ML models
- Batch inference with database output

## Why not Deep Learning?
In many industrial contexts, simplicity, stability and maintainability are preferred over complex models.
